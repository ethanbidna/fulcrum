## Evidence

| Invariant | Review and existing executable checks |
|---|---|
| Tasks are only the user's work | `flow-object.schema.json` rejects Task assignees and responsible entities; schema tests cover rejection. P2/P3 and command tests require explicit commitment proofs for AI Task/Dependency creation. |
| One graph; initiative is not a node | Schema permits four node types only. Domain invariants validate initiative membership, edge scope and the `contains` forest. No independent child-graph record exists. |
| `contains` is not an execution prerequisite or completion rule | Card-state helpers evaluate prerequisites through `depends_on`; no command completes a parent from child completion. Reference and production projections share golden expectations. |
| Contextual Questions | Question/assertion targets are validated against initiative/node/edge membership. Policy requires materiality and dedupe keys; protected updates produce suggestions and a contextual question. |
| Exact MoSCoW; objective rank separate | Canonical schema restricts MoSCoW to the four `_do` values. Objective rank and initiative MoSCoW use separate commands; tests reject `must_have`. |
| Protected AI writes; evidence; undo | Reviewed `policy.ts`, command authorization, transaction staging and replay. AI activation and settings changes are denied; protected-field updates preserve values. Evidence-backed suggestions, manual corrections after replay, change/run undo and scoped MCP resolution tests cover implemented paths. |
| Source content is untrusted | Domain command names/arguments are catalog validated; actor/device, validators and reconciliation proof are trusted application ports. No implemented source-to-command execution path exists. C6/I5 must preserve this boundary. |
| Shared writes and layer boundaries | `Domain.execute` stages commands before durable commit. Store handles I/O; domain imports no runtime/network modules. Layer lint and boundary tests enforce declared package imports. |
| Portable workspace layout | Store writes manifest/log/checkpoints only; local identity and locks require a directory outside the workspace. Reader rejects symlinked children, placeholders and sequence collisions. Store tests exercise actual files and process crashes. |
| No prohibited dashboard or hosted inference | `apps/desktop/src/index.ts` is a scaffold. Production packages contain no percent-completion output, status-column UI, avatar, embedded chat, generated summary renderer or hosted inference/telemetry call. The UI needs another audit once implemented. |
| Public synthetic fixtures | Existing schema/fixture tests check synthetic UUIDs and absence of email addresses. Targeted source/fixture scans found no committed machine paths, private-key headers or token literals. No tracked weights, databases or environment files; the tracked S7 icon is outside this core review's visual scope. |

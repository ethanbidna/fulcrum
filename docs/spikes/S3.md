# S3 — Graphiti comparison

## Current outcome

Engineering harness prepared; model and hardware comparison pending. Native
SQLite remains the shipping ContextIndex. Graphiti and its graph store are not
bundled or enabled by onboarding. Owner authorized implementation before tests
on 2026-11-10; that does not accept a model or complete an Owner box.

The native smoke ingested/rebuilt the same 48 synthetic workspace episodes and
resolved all seven exact identity/ambiguity/abstention cases with zero LLM calls.
Its local timing/RSS is recorded in S3-results/native-smoke.json, not a controlled
Intel/Apple Silicon throughput recommendation. Expected answers are excluded
from model ingestion and resolution prompts.

A no-inference Graphiti store probe failed on Intel with OSError 86, bad CPU type
in the installed FalkorDBLite 0.11.0 redis-server executable. The installed Python
adapter imports with telemetry disabled. No Graphiti model request, alias-quality
measurement, graph rebuild or Apple Silicon test was run. The failure is recorded
without local paths in S3-results/intel-store-smoke.json.

## Store decision and maintenance

| Candidate | Current evidence | Decision |
|---|---|---|
| Native SQLite | Production ContextIndex, exact alias/external-ID and ambiguity tests; local smoke | Retain as default |
| Kuzu | Graphiti 0.31.2 marks its extra deprecated because upstream is unmaintained | Do not start a new integration |
| Neo4j Community | Separate GPL graph server; additional installation/resource burden | Not added for this embedded trial |
| FalkorDBLite 0.11.0 | Current Graphiti-supported Python 3.12 embedded option; wrapper BSD, bundled FalkorDB engine separately SSPL; Intel wheel execution failed | Internal optional experiment only; no product distribution approval |

A BSD wrapper label does not settle the embedded engine's distribution license.
FalkorDB's upstream SSPL text and bundled engine/license inventory need explicit
review before shipping, independently of performance. No license/legal approval
is inferred from installing a test wheel. Current packaging deliberately excludes
both Graphiti and graph servers. ADR-0025 authorizes only the isolated spike.

## Comparison contract

[The procedure](../../spikes/s3/README.md) pins Graphiti 0.31.2 and its transitive
packages in uv.lock. It uses the existing scenario-6 fixtures plus two unresolved
cases and a snapshotEpisodes export. The production native index and proposed
Graphiti adapter receive the same canonical episodes. Model extraction cost and
loss of structured aliases remain visible; no gold answers repair predictions.
The Graphiti adapter's exact scope, timings, request counters, resource limits,
rebuild method and limitations are documented in the procedure.

| Hardware | Current recommendation | Missing acceptance |
|---|---|---|
| Intel | No-go for the current embedded wheel; retain native index | Supported store binary, local model trials, full resource/quality review |
| Apple Silicon | Native default; Graphiti adoption pending | Store probe, repeated initial/rebuild/alias trials, licensing/distribution review |

Do not replace missing numbers with thresholds chosen to pass. The decision
checkpoint must compare benefit over native against accuracy, unsafe resolution,
latency, memory, setup and licensing cost. A false merge must never authorize
canonical entity merging or protected-field writes.

# U7 Timeline

Timeline appears only for an initiative or node with a target date. Milestones
remain canonical nodes; dependencies include undated prerequisite links. There
is no inferred scheduling, date propagation or completion calculation. A direct
Timeline URL for undated work explains that dates are optional.

Use `pnpm dev`, open a dated synthetic initiative, choose Timeline and follow a
work/prerequisite link to its canonical inspector. Check Back and keyboard links.
A small SVG supplies the date axis; the semantic list contains the same dates
and states. vis-timeline would add lifecycle/bundle cost without needed zoom,
drag scheduling or interval editing. No new dependency, schema or ADR change.

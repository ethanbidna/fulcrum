# P1 MCP setup and scope review

Settings → MCP is the trusted local control surface. Access starts disabled;
enabling requires the sharing disclosure. Read-only, excerpts off and questions
visible are the defaults. Selected initiative/category scopes apply to reads,
search and Domain write policy. Empty selections share nothing. Cross-scope
record references deny the dependent view rather than expose private titles or
claim that hidden prerequisites are satisfied. Scoped legacy board/rail queries
are denied; use list/get/graph tools. Scoped objectives include linked objectives.

Activity records requested/allowed/failed/denied calls and returned IDs locally,
without argument content. A private 4 MiB log limit stops access if logging can
no longer be guaranteed; it does not silently drop calls. Settings shows the
200 most recent entries. Source excerpts are wrapped as untrusted quotations.
History suppresses source/assertion payloads and raw command arguments.

The installer merges only the Fulcrum entry, preserving other client settings
and backing up original bytes. Broken JSON, symlinks and unavailable builds fail
without replacing the existing file. Headless launch reads the saved private
workspace profile and MCP opt-in, connects first, then launches only the bundled
core with fixed argument names. The store lock arbitrates concurrent launches.

## Automated evidence

Real socket/SDK tests exercise scoped reads and writes, read-only/disclosure,
canonical actor and retry/undo, and exact UI/MCP operation parity (scenario 11).
Elicitation-capable clients accept/decline through the installed SDK; decline
writes nothing. Clients without forms still need explicitly enabled write mode.
Filesystem tests cover non-destructive client installation and symlink logs.
Injected lifecycle ports check opt-in, connect-first, fixed launch arguments and
a bounded startup failure. They do not establish packaged headless startup.

Storybook tests cover disclosure gating, default read-only/excerpt settings,
selected scopes, installation confirmation, activity, load/retry and failed
saves. Captures: `apps/desktop/.impeccable/review/p1/`.

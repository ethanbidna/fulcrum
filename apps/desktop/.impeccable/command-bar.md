# Command bar

THESIS: Describe a change, inspect its consequences, apply once.
OWN-WORLD: Extend Fulcrum's existing white workspace, neutral navigation, muted
blue action/focus, system typography and restrained separators. No new identity,
AI glow, chat transcript or promotional copy.
STORY: The owner wants both in-app natural-language commands and external MCP,
and dislikes dependence on buttons and dropdowns. The command input leads;
manual attribute editing becomes a secondary disclosed fallback.
FIRST VIEWPORT: One inline command input below the page heading; keyboard entry
and a quiet submit icon. A structured review appears in that same location,
above the still-visible graph. Desktop and narrow layouts preserve context.
FORM: Operate; existing composition/code-led extension. No comp/concept round.
Review names created objects/relationships and before/after field values. Apply
is explicit, keyboard accessible and atomic; Escape cancels planning/review.
QUALITY BAR: No writes while planning; retained drafts/errors; no raw JSON or
UUID-only descriptions; readable 390/644/1280 layouts; no permanent conversation.
FINISH: Capture desktop, mobile and 644px request/review states in one inspection
batch, run detector once, then fresh finish reviewer and documenter handoffs.

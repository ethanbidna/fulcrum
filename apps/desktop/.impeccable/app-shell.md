# App shell

Mode: Operate. Scope: U1 navigation, connection states and foundational tokens.
The documented sidebar and design rules are pinned; build code-first.

## Direction contract

THESIS: Four stable destinations around one workspace. Preserve clear location
while later portfolio and graph workflows are added.

OWN-WORLD: White work area, cool neutral sidebar, restrained blue selection,
system type, fine separators, consistent outline icons and the original mark.

STORY: The user can identify their location, move between destinations and tell
whether the local core is reachable. Questions show only a quiet live count.

FIRST VIEWPORT: A 216px sidebar, brand above the navigation, Settings at its foot.
The main area has a left-aligned page title and an honest build-scope empty state.
Connection status sits at the sidebar foot; recovery is inline. Small viewports
move navigation above content without hiding destinations.

FORM: Owner-pinned desktop shell, no concept roll. Signature interaction: keyboard
navigation retains a clear selected destination and moves focus to its heading.
No decorative entrance motion; short hover/selection feedback respects reduced motion.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

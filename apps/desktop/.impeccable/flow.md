# Initiative flow

Mode: Operate. U3 extends the owner-pinned shell and portfolio. Issue #17 and
DESIGN_RULES govern; preserve palette, typography and navigation. Code-first.

THESIS: One initiative, one editable process graph with explicit relationships.
OWN-WORLD: Neutral canvas, muted blue selection, fine borders and distinct
square Task, hourglass Dependency, diamond Decision and flag Milestone marks.
STORY: Open a portfolio card, follow top-to-bottom work, add or rename a node,
connect with a typed relationship, and undo a durable edit without leaving.
FIRST VIEWPORT: Initiative breadcrumb/title and quiet attributes; compact local
actions above a large pan/zoom canvas. Selection exposes local edit/delete;
full attributes and focused navigation belong to U4. Narrow windows keep the
same canvas with wrapped controls, not a separate graph or modal editor.
FORM: Inherit the specified world. ELK layered layout, light visual group frames,
conditional route labels, dashed inferred records and read-only shared references.
Positions/zoom are ephemeral presentation state; semantic edits use Domain.execute.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

# Portfolio board

Mode: Operate. Extend the owner-pinned U1 shell. U2 acceptance is issue16;
all existing DESIGN_RULES remain binding. Code-first, no concept round.

## Direction contract

THESIS: Initiatives are the primary work objects; one meaningful state per card.

OWN-WORLD: Inherit the neutral shell, system typography and muted blue selection.
Cards use one fine border, generous internal spacing and restrained metadata.

STORY: The user scans outcomes and next actions, changes grouping independently
of sort, reorders manually, and consults a quiet context rail when useful.

FIRST VIEWPORT: Existing sidebar and title. A compact Group by/Sort toolbar and
New initiative action sit above section headings and a two-column card grid.
A narrow right rail contains next actions, waiting and meaningful changes; it
collapses in place and moves below the board on small windows.

FORM: Precisely specified extension of U1, no roll. Signature interaction:
manual card movement changes only rank through Domain.execute, never grouping.
Keyboard access accompanies dragging; acknowledged state drives the display.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
